# Changelog

## 0.1.0

Initial release of `@t128n/ui`.

- Semantic token pipeline with light and dark themes, three densities and
  none/faint/visible hairlines.
- Svelte 5 components for actions, forms, search, navigation, shell, data
  display, chips, overlays, feedback, documents and calendars.
- Reference views for Issues, Board, Table database, Document page, Settings,
  Inbox, Overview, Calendar, Empty workspace and Error.
- Generated package barrel, `dist/tokens.css`, `dist/layouts.css`, `.svelte`
  sources and type declarations.
- Storybook stories with theme, density and lines controls.
- Static package checks for raw hex, raw pixel values, primitive-token use and
  the public barrel.
