# t128n design system

The reference implementation of [DESIGN.md](./DESIGN.md): one calm, dense, document-like interface, built with Svelte 5, bits-ui and Storybook.

**Stack:** Svelte 5 (runes) · Vite 7 · Storybook 10 (`@storybook/svelte-vite`) · bits-ui · Carbon icons

## Quick start

```bash
npm install
npm run storybook        # http://localhost:6006
npm run build-storybook  # static build in storybook-static/
npx playwright install chromium  # once, for the preview capture
npm run screenshots      # build, render every view in light + dark to docs/screenshots/
npm run check            # svelte-check
```

## The Storybook is the reference

`DESIGN.md` is the specification; every story is a composition of it. Until a view has a story, the view is not built (DESIGN.md section 8).

The toolbar carries the three container settings from the spec:

| Toolbar | Values | Token effect |
|---|---|---|
| Theme | Light / Dark | surface, text, status and border values |
| Density | Compact / Default / Comfortable | `--row-h`, `--row-h-sm`, `--control-h` |
| Lines | None / Faint / Visible | `--border-alpha` |

They are set as `data-theme`, `data-density` and `data-lines` on the preview root, exactly as any container in an app would carry them.

## Layout

```
src/
  lib/
    styles/
      tokens.css        # primitives, semantic tokens, density, type shorthands
      base.css          # reset, focus, reduced motion
      patterns.css      # shared structural geometry: table, list, board, properties
    components/         # interactive primitives + their stories
    views/              # the ten views from DESIGN.md section 8 + stories
  stories/foundations/  # token, type, density and layout specimens
.storybook/
  main.ts
  preview.ts            # theme/density/lines globals
scripts/
  screenshots.mjs       # static server + Playwright capture
docs/screenshots/       # PR preview: every view, both themes
```

## Conventions

- Components read **semantic tokens only** (`--surface-*`, `--text-*`, `--border-*`, status/tag tokens, `--type-*`). `--prim-*` is off limits.
- No raw hex, no raw pixel sizes outside the ladders in DESIGN.md 2.5–2.8, no font sizes or weights outside the type shorthands.
- Use the `--type-*` shorthand: `font: var(--type-body)`. Never set `font-size` or `font-weight` directly.
- Selection is a tint (`--state-selected`) and focus is an outline. No accent edges, no toasts.
- Every icon-only button carries an `aria-label`; every input has a visible label.
- New work lands with a story, controls where props exist, and a note naming the principles that apply.
