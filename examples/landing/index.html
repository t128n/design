A Design System for People Who Ship.

t128n is a personal, utility-first visual language for tools and the sites that explain them. Calm surfaces, one accent, and rules that hold under pressure.

Open the Examples Read the Spec

What Holds It Together.

Every Pixel Carries Information.

Remove an element and comprehension should drop. If it does not, it was decoration.

One Accent, Earned.

Blue marks the wordmark, action, selection, focus, and current state. Nothing else competes for it.

Structure from Borders.

1px rules and alignment do the work that shadows usually fake.

The Parts, at Rest.

Controls, fields, and tags from the same token block. Disable the shadows and the hierarchy survives.

Start with a Shell.

Pick the surface before the page. Tokens travel; layout does not.

  • Content Shell 72ch measure, no sidebar, reading first.
